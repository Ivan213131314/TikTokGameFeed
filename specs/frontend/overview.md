# Спецификация Frontend

Этот документ описывает архитектуру и структуру мобильного приложения (Frontend части).

## 1. Обзор Модуля

**Frontend** построен на React Native с использованием **Expo**. Он отвечает за отображение пользовательского интерфейса, навигацию и управление состоянием экранов.

- **Основная ответственность**: Отображение ленты игр и профиля пользователя.
- **Технология**: Expo SDK 54, Expo Router v6.

## 2. Структура Навигации

Навигация реализована через **Expo Router** (файловая маршрутизация в папке `app/`).

### Основные Экраны:
- **Root Layout (`app/_layout.tsx`)**:
  - Содержит `GestureHandlerRootView` и `StatusBar`.
  - Оборачивает все приложение.

- **Tab Layout (`app/(tabs)/_layout.tsx`)**:
  - Реализует нижнюю панель навигации (Bottom Tabs).
  - Экраны:
    1.  **Feed (`app/(tabs)/index.tsx`)**: Главная лента с играми.
    2.  **Profile (`app/(tabs)/profile.tsx`)**: Профиль текущего пользователя.

## 3. Ключевые Компоненты

### `GameContainer` (`src/components/GameContainer.tsx`)
- **Ответственность**: Обертка для отдельной игры в ленте.
- **Функции**:
  - Рендерит `WebView` с HTML контентом игры.

### `InteractionSidebar` (`src/components/InteractionSidebar.tsx`)
- **Ответственность**: UI элементы поверх игры (справа).
- **Элементы**:
  - Кнопка аватара (переход к профилю автора).
  - Кнопка лайка (с счетчиком).
  - Кнопка комментариев (открывает модальное окно).

### `CommentsModal` (`src/components/CommentsModal.tsx`)
- **Ответственность**: Отображение списка комментариев и формы добавления.
- **Поведение**: Выезжает снизу (Bottom Sheet или Modal).

## 4. Управление Состоянием и Данными

- **Локальное состояние**: Используется `useState` внутри компонентов для управления UI (например, `isLiked`, `commentsVisible`).
- **Загрузка данных**: Данные загружаются напрямую через `GameStorageService` (Supabase) в `useEffect` хуках экранов.
- **Кэширование**: На данный момент явного глобального кэширования (Redux/Zustand) нет; данные обновляются при фокусе или явном действии.

## 5. Взаимодействие с Модулями

- **Game Engine**: Frontend передает HTML строку в WebView.
- **Backend**: Frontend вызывает методы `GameStorageService` для получения списка игр, лайков и отправки комментариев.

## 6. Known Limitations

- **Список игр**: Загружается фиксированным списком (limit 50), пагинация (infinite scroll) на данный момент не полностью реализована или упрощена.
- **Производительность**: Использование множества WebView в `PagerView` может требовать оптимизации памяти (сейчас рендерится список `GameContainer`).
