# Спецификация Service Layer

Этот документ описывает слой бизнес-логики и сервисов приложения.

## 1. Обзор

Сервисный слой изолирует логику работы с данными от React компонентов. Основным (и пока единственным) сервисом является **GameStorageService**.

## 2. GameStorageService (`src/services/GameStorageService.ts`)

Синглтон-объект, предоставляющий методы для работы с играми и социальными функциями.

### Основные Ответственности:
1.  **Загрузка данных**: Получение списка игр (общий фид) и игр конкретного пользователя.
2.  **Трансформация данных**: Преобразование "сырых" данных из Supabase в TypeScript модели (`GameModel`, `CommentModel`).
3.  **Управление файлами**: Чтение содержимого файлов при загрузке новой игры (через `expo-file-system`).
4.  **Социальные действия**: Лайки, добавление комментариев.

### API Методы (Public Surface)

- `initialize()`: Заглушка для инициализации (сейчас no-op).
- `getGames()`: Возвращает список последних игр (`limit 50`).
- `getUserGames(userId)`: Возвращает игры конкретного пользователя.
- `addGame(name, sourceUri)`:
  - Читает файл по `sourceUri`.
  - Загружает контент и метаданные в Supabase.
  - Требует авторизации.
- `deleteGame(id)`: Удаляет игру (только свою).
- `toggleLike(gameId)`: Ставит или убирает лайк.
- `getGameStats(gameId)`: Возвращает кол-во лайков, комментариев и статус `isLiked` для текущего пользователя.
- `getComments(gameId)`: Возвращает список комментариев с профилями авторов.
- `addComment(gameId, content)`: Добавляет комментарий.
- `seedDefaultGames()`: Создает дефолтную игру ("Falling Square"), если пользователь авторизован и хочет заполнить БД.

## 3. Обработка Ошибок

- Сервис логирует ошибки в консоль (`console.error`).
- В большинстве методов при ошибке возвращается пустой массив или дефолтное значение, чтобы не крашить UI.
- Методы записи (`addGame`, `addComment`) могут выбрасывать исключения, которые должны обрабатываться в UI.

## 4. Зависимости

- **Supabase Client**: Импортируется из `../../lib/supabase`.
- **Expo FileSystem**: Используется динамический импорт `require('expo-file-system/legacy')` для совместимости.
