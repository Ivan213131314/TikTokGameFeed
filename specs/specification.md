# Спецификация Проекта TikTokGameFeed

Этот документ является ГЛАВНОЙ спецификацией проекта. Она описывает высокоуровневую структуру, архитектуру и служит картой навигации по модульным спецификациям.

## 1. Обзор Проекта

**TikTokGameFeed** — это мобильное приложение, предоставляющее пользователям ленту казуальных HTML5-игр в формате, аналогичном TikTok.

### Основные цели:
- Предоставление бесконечной ленты игр с быстрым доступом.
- Социальное взаимодействие: лайки, комментарии, профили пользователей.
- Возможность загрузки и создания пользовательских игр.
- Поддержка "моментального" геймплея без долгих загрузок.

### Границы проекта (Scope):
- **Входит в scope**: Мобильное приложение (iOS/Android), интеграция с Supabase (Auth, DB), рендеринг HTML5 игр в WebView, лента рекомендаций (базовая хронология), профили пользователей.
- **Out of scope**: Слезные онлайн-мультиплеерные игры (real-time server authority), сложная модерация контента (в текущей версии), нативная разработка игр (только HTML5/JS).

## 2. Высокоуровневая Архитектура

Система состоит из трех основных частей:

1.  **Frontend (Mobile App)**
    - Написан на React Native с использованием Expo.
    - Отвечает за навигацию (Feed, Profile), UI оболочку и взаимодействие с пользователем.
    - Использует WebView для отображения игрового контента.

2.  **Game Engine (WebView Container)**
    - Изолированная среда выполнения HTML5 игр внутри приложения.
    - Обеспечивает мост (Bridge) между игрой и приложением для передачи счета, состояния Game Over и управления.

3.  **Backend (BaaS - Supabase)**
    - Хранение данных (игры, пользователи, лайки, комментарии).
    - Аутентификация.
    - Хранение кода игр (как текстовый контент в БД).

## 3. Технологический Стек

- **Язык**: TypeScript
- **Фреймворк**: React Native (Expo SDK 54)
- **Навигация**: Expo Router (v6)
- **Backend / База данных**: Supabase (PostgreSQL)
- **Игровой рендеринг**: `react-native-webview`
- **UI Компоненты**: `react-native-pager-view` (лента), `@expo/vector-icons`

## 5. Маршрутизация Спецификаций

Ниже приведен список модулей и ссылки на их детальные спецификации.

### Frontend
**Ответственность**: Пользовательский интерфейс, навигация, отображение ленты.
**Файл спецификации**: [specs/frontend/overview.md](frontend/overview.md)
**Когда смотреть**: При изменении UI, добавлении экранов, логике навигации.

### Backend & Data
**Ответственность**: Схема данных, аутентификация, API вызовы к Supabase.
**Файл спецификации**: [specs/backend/overview.md](backend/overview.md)
**Когда смотреть**: При изменении структуры БД, правил доступа (RLS), логики запросов.

### Game Engine (WebView Bridge)
**Ответственность**: Контракт взаимодействия между HTML5 игрой и React Native приложением.
**Файл спецификации**: [specs/modules/game_engine.md](modules/game_engine.md)
**Когда смотреть**: При создании новых игр, изменении способа подсчета очков, обработке Game Over.

### Services Layer
**Ответственность**: Бизнес-логика, не зависящая от UI (загрузка игр, управление состоянием).
**Файл спецификации**: [specs/modules/services.md](modules/services.md)
**Когда смотреть**: При изменении логики `GameStorageService`, кэшировании, работе с файловой системой.
